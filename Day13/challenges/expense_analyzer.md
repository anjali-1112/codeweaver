Weekly Expense Analyzer

Approach:

I stored the seven daily expenses in an array. I used separate functions to calculate the weekly total, average, highest expense, lowest expense, and the number of days that exceeded the daily budget.

I used for loops to traverse the array and process each expense. I also created a function to check whether the total weekly spending stayed within the given weekly budget.


16 — Stretch Challenge: Weekly Expense Analyzer

Calculate average daily spending.

Find the highest expense.

Find the lowest expense.

Count how many days exceeded a given daily budget.

Determine whether the week overall stayed within a weekly budget.
