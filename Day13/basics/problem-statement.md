 Engineering Problem — Arrays

Problem Statement

We need to store multiple related values under one variable instead of creating a separate variable for each value. The collection should be able to grow easily when more values are added. We should also be able to access any individual value and process all values using a loop.

 Constraints

 Use one variable to represent the complete collection.
 Allow access to any individual value using its position.
 Process all values using a loop instead of writing separate code for each value.
