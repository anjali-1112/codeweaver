What problem do arrays solve?

-> Arrays solve the problem of storing multiple related values in one variable. Instead of creating separate variables for every student, product, or score, we can store all of them in one organized collection.


Why does indexing start at 0?

-> Array indexing starts at 0 because the first element is considered to be at an offset of zero from the beginning of the collection. Therefore, the first element has index 0, the second has index 1, and so on.


What is the difference between length and the last valid index?

-> The length represents the total number of elements in an array. The last valid index is always length - 1 because array indexing starts from 0.
